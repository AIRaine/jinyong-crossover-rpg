# 穿越諧音武俠文字 RPG

純前端（Vite + React + TypeScript + Tailwind）手遊直式文字 RPG。人名／地名／武學皆為諧音代稱。

## 本機開啟

```bash
cd jinyong-crossover-rpg
npm install
npm run dev
```

瀏覽器開啟終端機顯示的位址（預設 `http://127.0.0.1:5173`）。建議用開發者工具切換手機直式寬度（約 390px）。

## 建置

```bash
npm run build
npm run preview
```

## 階段內容（目前至階段五）

- 開局職業、序章、裝備／武學／採集煉丹（階段一～三）
- **戰鬥**：`combatMath` 傷害公式＋3v3 可玩 UI（中毒／妖光眩暈／急救）
- **門派**：8 個諧音門派，入門／貢獻／晉升
- **群英**：送禮、最多 2 人入隊、好感 100 結俠侶（雙修加成）
- **旬制**：推進旬日、5 年主線＋奇遇、傳聞 3 條、商道被動銀兩
- **榜單**：天／地／神兵／富豪四榜骨架＋切磋（3v3）
- **商城**：銀兩店、元寶抽卡（年份封印品質＋保底）、模擬儲值／月卡（體驗，不扣款）
- **NG+**：五年主線完成後可於系統結算多周目骨架
- 存檔 `migrateSaveData`（v5）

真實金流與上線部署另開「上線階段」。
