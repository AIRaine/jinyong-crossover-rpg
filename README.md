# 穿越諧音武俠文字 RPG

純前端（Vite + React + TypeScript + Tailwind）手遊直式文字 RPG。人名／地名／武學皆為諧音代稱。

## 本機開啟

```bash
cd jinyong-crossover-rpg
npm install
npm run dev
```

瀏覽器開啟終端機顯示的位址（預設 `http://127.0.0.1:5173`）。建議用開發者工具切換手機直式寬度（約 390px）。

## 建置

```bash
npm run build
npm run preview
```

## 內容規模（世界擴充後）

| 項目 | 約略數量 |
|------|----------|
| 開局職業 | 12（含八大公關、無業等） |
| 地點 | 18（4 主城＋門派駐地＋秘境／路點） |
| NPC | 26（六部諧音作品切片） |
| 武學 | 42 |
| 裝備 | 36 |
| 主線 | 5 年（含可選結局分支） |
| 奇遇 | 22 |
| 門派 | 9 |
| 科技 | 17 |

另含榜單切磋、元寶抽卡／月卡（模擬）、NG+ 骨架。真實金流另開上線階段。
